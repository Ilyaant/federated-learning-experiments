# Эксперименты на датасете Brodatz
В этой ветке находится код для обучения различных архитектур нейронных сетей на текстурном датасете Brodatz.
## Используемые модели
На данный момент сравниваются следующие архитектуры:
- efficientnet_v2_s
- ConvNextV2Model
- fastvit_t8
- fastvit_s12
- faster_vit_0_224
- mobilenetv5
## Подготовка данных
Для подготовки датасета Brodatz, расположенного в папке `data/brodatz`, выполнить:
```bash
python src/split_data.py
```
Датасет, готовый для экспериментов, появится в папке `data/brodatz_exp`.
## Запуск эксперимента
Для запуска эксперимена с выбранной моделью из списка выше выполнить:
```bash
python run_experiment.py --model=<model_name>
```
## Результаты экспериментов
Запускались эксперименты со следующими параметрами:
- Размер батча: 32
- Ресайз изображений до: 224*224
- Количество эпох: 25

Результаты:

| Модель                  | Параметры (млн) | Размер (МБ) | Видеопамять (ГБ) | Accuracy | F1-score | Время обучения (чч:мм) |
|-------------------------|-----------------|-------------|------------------|----------|----------|------------------------|
| ConvNextV2 (2023)       | 28.6            | 115         | ~6               | 0.8877   | 0.8794   | 11:26                  |
| EfficientNetV2_s (2021) | 21.5            | 83          | ~5               | 0.9213   | 0.9180   | 11:27                  |
| FastViT T8 (2023)       | 4.0             | 15          | ~2               | 0.9311   | 0.9256   | 4:39                   |
| FastViT S12 (2023)      | 9.5             | 36          | ~3               | 0.9277   | 0.9266   | 7:13                   |
| FasterViT 0 (2023)      | 31.4            | 121         | ~6               | 0.9259   | 0.9245   | 7:18                   |
| MobileNet V5 (2025)     | 296             | 1130        | ~11              | 0.9005   | 0.9013   | 49:46                  |

Размер — веса модели в FP32. Видеопамять — пиковое потребление при обучении с параметрами выше (batch 32, 224×224, FP32, AdamW).

В итоге, для дальнейших экспериментов выбрана модель FastViT T8 (2023) как лучшая по скорости и качеству.
